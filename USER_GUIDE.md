# User Documentation: Campus Events Discovery App

Welcome to the **Campus Events Discovery App**! This guide explains how to use the platform as a Student or an Administrator.

## 1. Getting Started

### Registration & Login
- **Students**: Click "Sign Up" in the header to create an account. You will need your Student ID, Department, and Year.
- **Login**: Use your username and password to access personalized features.
- **Roles**: 
  - **Student**: Can browse and RSVP.
  - **Organizer**: Can create and manage their own events.
  - **Admin**: Full control over students and all events.

## 2. For Students

### Discovering Events
- **Explore**: Use the "Explore" page to browse all live events.
- **Search & Filter**: Search by title or filter by category (Sports, Arts, Tech, etc.).
- **Calendar View**: View events on an interactive monthly calendar.

### Managing Registrations
- **RSVP**: Click "Join Now" on any event page to secure your spot.
- **QR Ticket**: Once RSVPed, a personalized QR code will appear on the event detail page. Show this at the venue!
- **My Events**: Access your dashboard to view upcoming registrations and saved favorites.
- **Cancel RSVP**: If you can no longer attend, you can cancel your registration from the event detail page.

## 3. For Event Organizers

### Managing Your Events
- **Create Event**: Use the "Organize" tab to submit a new event request. Provide a title, description, image, and deadline.
- **Approval**: New events are marked as "Pending" until an Admin approves them.
- **Registrations**: You can view and export (CSV) the list of students who have registered for your events.
- **Notifications**: Use the "Notify Attendees" feature to send a mass email update to all registered students.

## 4. For Administrators

### Admin Dashboard
- **Analytics**: View core metrics like Total Registrations, Popular Categories, and Event Status summaries.
- **Approval Workflow**: Review pending event requests and "Approve" or "Reject" them.
- **Student Management**: View all registered students and manage their accounts.
- **System Control**: Admins have the authority to edit or delete any event on the platform.

## 5. Bonus Features
- **Dark Mode**: Toggle between light and dark themes using the moon/sun icon in the sidebar.
- **AI Chatbot**: Ask the event assistant (bottom right) for recommendations!
- **Countdown**: Every upcoming event features a live countdown timer.
